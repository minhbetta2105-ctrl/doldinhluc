[MUC1] BẢNG NHẬN DIỆN CÁC LOẠI BẢNG TRONG MỌI ĐỀ THI & CÁCH ĐỔI TÊN
================================================================================

Khi cầm tờ đề thi bất kỳ, bạn đừng慌 (hoảng). Mọi đề thi chỉ xoay quanh các bảng
sau đây. Hãy nhìn bảng trên tờ đề và xác định tên tương ứng:

1. `BangChinh` (Bảng đối tượng trung tâm - phía MỘT):
   - Là bảng chứa thông tin chính mà hệ thống quản lý.
   - Thường có các trường:
     + Tên/Tiêu đề: `name` hoặc `title` hoặc `Ten` hoặc `TieuDe`
     + Ngày tháng: `start_date` / `published_date` / `NgayTao` / `event_date`
     + Giới hạn số lượng / Tồn kho: `max_students` / `stock` / `capacity` / `max_guests`
     + Giá tiền (nếu có): `price` / `fee`

2. `BangPhu` (Bảng danh mục hoặc nhân sự đi kèm):
   - Ví dụ: Giảng viên (`Instructor`), Chuyên mục (`ChuyenMuc`), Kho (`Kho`),
     Khách hàng (`Customer`), Bác sĩ (`Doctor`), Diễn giả (`Speaker`).

3. `BangTrungGian` (Bảng nối Nhiều - Nhiều):
   - Dạng A (Không có trường phụ): Chỉ là một dòng `ManyToManyField` nằm trong bảng
     khác (như trường `instructors` nằm trong `Lesson`).
   - Dạng B (Có trường phụ như `ThuTu`, `SoLuong`, `Role`): Đề bắt tạo thành 1 bảng
     riêng (như `BaiVietChuyenMuc` ở đề 105, `KhoHangHoa` ở đề 109) -> Dùng `through="..."`.

4. `BangGiaoDich` (Bảng phát sinh khi người dùng Đăng ký / Đặt hàng / Đánh giá):
   - Ví dụ: Đăng ký học (`Enrollment`), Đơn hàng (`Order`), Đánh giá (`Review`),
     Đặt phòng (`Booking`), Lịch khám (`Appointment`).
   - Luôn có 1 khóa ngoại (`ForeignKey`) chỉ về `BangChinh`.

4.1. CÁCH VIẾT CÁC TRƯỜNG DỮ LIỆU CƠ BẢN:
- Chuỗi ký tự tối đa N ký tự : models.CharField(max_length=N)
- Văn bản dài (Mô tả/Nội dung): models.TextField()
- Số nguyên                   : models.IntegerField()
- Số thập phân (Giá/Tiền)     : models.DecimalField(max_digits=10, decimal_places=2)
- Ngày tháng                  : models.DateField()
- Ngày và giờ                 : models.DateTimeField()
- Email                       : models.EmailField()

* Các chữ đi kèm trong ngoặc `(...)` khi đề yêu cầu:
- Đề ghi "bắt buộc"           : Không cần ghi gì thêm (hoặc ghi `blank=False`).
- Đề ghi "không bắt buộc"     : Thêm `blank=True, null=True` vào trong ngoặc.
- Đề ghi "không trùng lặp"    : Thêm `unique=True` vào trong ngoặc.
- Đề ghi "khóa chính tự tăng" : id = models.AutoField(primary_key=True)
- Đề ghi "liên kết auth_user" :
  Ở đầu file thêm: `from django.conf import settings`
  Trường liên kết viết: `NguoiTao = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE)`


4.2. BA DẠNG QUAN HỆ TRONG `models.py` (ĐỀ NÀO CŨNG RƠI VÀO 1 TRONG 3 DẠNG NÀY):

--------------------------------------------------------------------------------
DẠNG 1: QUAN HỆ 1 - NHIỀU (Dùng `ForeignKey` - đặt ở bảng phía NHIỀU)
(Ví dụ: 1 Khách hàng có nhiều Đơn hàng; 1 Khóa học có nhiều Học viên đăng ký)
--------------------------------------------------------------------------------
class BangChinh(models.Model):
    name = models.CharField(max_length=200)
    start_date = models.DateField()
    max_students = models.IntegerField()

    def __str__(self):
        return self.name


class BangGiaoDich(models.Model):
    student_name = models.CharField(max_length=100)
    student_email = models.EmailField()
    enrolled_date = models.DateField()

    # Khóa ngoại nối về BangChinh:
    # - Dùng on_delete=models.CASCADE nếu đề bảo xóa bảng chính thì xóa bảng con.
    # - Dùng on_delete=models.PROTECT nếu đề bảo không cho xóa khi còn dữ liệu liên quan (như Đề 111).
    course = models.ForeignKey(
        BangChinh,
        on_delete=models.CASCADE,
        related_name="enrollments"
    )

    def __str__(self):
        return self.student_name


--------------------------------------------------------------------------------
DẠNG 2: QUAN HỆ NHIỀU - NHIỀU KHÔNG CÓ BẢNG TRUNG GIAN PHỤ (Như Đềថ្មី)
(Đề chỉ ghi cột Kiểu dữ liệu là "Quan hệ nhiều - nhiều", KHÔNG bắt tạo bảng thứ 3)
--------------------------------------------------------------------------------
class BangPhu(models.Model):
    full_name = models.CharField(max_length=100)
    email = models.EmailField(unique=True)
    expertise = models.CharField(max_length=150)

    def __str__(self):
        return self.full_name


class BangChiTiet(models.Model):
    title = models.CharField(max_length=200)
    duration = models.IntegerField()
    course = models.ForeignKey(BangChinh, on_delete=models.CASCADE, related_name="lessons")

    # Quan hệ Nhiều - Nhiều trực tiếp (Django tự tạo bảng ngầm):
    instructors = models.ManyToManyField(BangPhu, related_name="lessons")

    def __str__(self):
        return self.title


--------------------------------------------------------------------------------
DẠNG 3: QUAN HỆ NHIỀU - NHIỀU CÓ BẢNG TRUNG GIAN RIÊNG (Như Đề 105, Đề 109 trong GOIY.txt)
(Đề cho hẳn 1 bảng thứ 3 nối 2 bảng kia, ví dụ `BaiVietChuyenMuc` hoặc `KhoHangHoa`)
--------------------------------------------------------------------------------
class ChuyenMuc(models.Model):
    Ten = models.CharField(max_length=200)

    def __str__(self):
        return self.Ten


class BaiViet(models.Model):
    TieuDe = models.CharField(max_length=250)
    NoiDung = models.TextField(blank=True)
    NgayTao = models.DateField()

    # Khai báo ManyToManyField có tham số through="Tên_Bảng_Trung_Gian":
    ChuyenMuc = models.ManyToManyField(
        ChuyenMuc,
        through="BaiVietChuyenMuc"
    )

    def __str__(self):
        return self.TieuDe


class BaiVietChuyenMuc(models.Model):
    BaiViet = models.ForeignKey(BaiViet, on_delete=models.CASCADE)
    ChuyenMuc = models.ForeignKey(ChuyenMuc, on_delete=models.CASCADE)
    ThuTu = models.IntegerField()  # Trường phụ nằm trong bảng trung gian

from django.contrib import admin
from django.db.models import Sum
from .models import *  # Dấu * giúp lấy toàn bộ các bảng đã viết bên models.py


@admin.register(BangChinh)   # Đổi `BangChinh` thành tên bảng đề yêu cầu tùy chỉnh Admin
class BangChinhAdmin(admin.ModelAdmin):
    # 1. Các cột hiển thị ra bảng quản trị:
    list_display = (
        "ten_truong_1",
        "ten_truong_2",
        "ten_truong_3",
        "cot_bo_sung",   # Tên hàm tự tính viết ở dưới
    )

    # 2. Ô tìm kiếm (Đề bảo tìm kiếm theo trường nào thì ghi vào):
    search_fields = ("ten_truong_1",)

    # 3. Bộ lọc bên phải (Đề bảo lọc theo trường nào thì ghi vào):
    list_filter = ("ten_truong_2",)

    # 4. Sắp xếp:
    # - Tăng dần : ordering = ("ten_truong_2",)
    # - Giảm dần : ordering = ("-ten_truong_2",)   (Có dấu trừ đằng trước)
    ordering = ("-ten_truong_2",)

    # 5. CHỌN 1 TRONG 4 DẠNG HÀM TÍNH CỘT BỔ SUNG DƯỚI ĐÂY TÙY THEO ĐỀ YÊU CẦU:

    # [Dạng 1 - Hay ra nhất]: Đếm số bản ghi bảng con (Số học viên đăng ký, Số đơn hàng, Số buổi học)
    def cot_bo_sung(self, obj):
        return obj.enrollments.count()  # Đổi `enrollments` thành related_name ở khóa ngoại

    # [Dạng 2]: Tính số lượng còn lại (Sĩ số tối đa trừ đi Số người đã đăng ký)

DẠNG FORM 1 (ĐỀ MỚI NHẤT): FORM ĐĂNG KÝ / GIAO DỊCH CÓ KIỂM TRA NHIỀU ĐIỀU KIỆN
(Ví dụ: Tạo Form đăng ký học, đặt vé, đặt phòng, ứng tuyển... có kiểm tra lỗi `clean`)
--------------------------------------------------------------------------------
from django import forms
from django.core.exceptions import ValidationError
from django.utils import timezone
from .models import *


class TenFormTheoDe(forms.ModelForm):
    # Nếu đề yêu cầu thêm 1 ô tích chọn xác nhận thông tin (như confirm_information):
    confirm_information = forms.BooleanField(
        required=True,
        label="Xác nhận thông tin",
        error_messages={"required": "Bạn phải xác nhận thông tin."}
    )

    class Meta:
        model = BangGiaoDich   # Đổi thành tên bảng lưu dữ liệu của Form
        fields = [
            "truong_ten",
            "truong_email",
            "truong_khoa_ngoai",
        ]

    # Hàm kiểm tra dữ liệu (Đề yêu cầu kiểm tra ý nào thì giữ lại khối `if` đó):
    def clean(self):
        cleaned_data = super().clean()

        ten = cleaned_data.get("truong_ten", "")
        email = cleaned_data.get("truong_email", "")
        so_luong = cleaned_data.get("so_luong")
        cha = cleaned_data.get("truong_khoa_ngoai")  # Đối tượng bảng chính được chọn

        # Ý 1: Kiểm tra độ dài tên tối thiểu N ký tự (VD: ít nhất 4 ký tự)
        if ten and len(ten.strip()) < 4:
            raise ValidationError("Họ tên phải có ít nhất 4 ký tự.")

        # Ý 2: Kiểm tra số lượng nhập vào phải lớn hơn 0 (hoặc trong khoảng 0 đến 5)
        if so_luong is not None and so_luong <= 0:
            raise ValidationError("Số lượng phải lớn hơn 0.")

        if cha:
            today = timezone.now().date()

            # Ý 3: Không cho đăng ký nếu đã khai giảng / đã diễn ra / quá hạn
            if cha.start_date <= today:
                raise ValidationError("Đã khai giảng hoặc quá hạn, không thể đăng ký.")

            # Ý 4: Không cho đăng ký khi số lượng đã đạt tối đa (max_students / capacity)
            if cha.enrollments.count() >= cha.max_students:
                raise ValidationError("Đã đạt số lượng tối đa, không thể đăng ký thêm.")

            # Ý 5: Không cho đặt số lượng vượt quá tồn kho (stock)
            # if so_luong and so_luong > cha.stock:
            #     raise ValidationError("Số lượng đặt vượt quá số lượng tồn kho.")

            # Ý 6: Không cho phép cùng một email (hoặc SĐT) đăng ký trùng vào cùng 1 mục
            if email:
                bi_trung = BangGiaoDich.objects.filter(
                    truong_khoa_ngoai=cha,
                    truong_email__iexact=email
                ).exists()
                if bi_trung:
                    raise ValidationError("Email này đã đăng ký mục này rồi.")

        return cleaned_data

def dang_ky_view(request):
    if request.method == "POST":
        form = TenFormTheoDe(request.POST)
        if form.is_valid():
            # Dùng commit=False để tự gán ngày đăng ký (enrolled_date) là hôm nay:
            ban_ghi = form.save(commit=False)
            ban_ghi.enrolled_date = timezone.now().date()
            ban_ghi.save()

            messages.success(request, "Đăng ký thành công!")
            return redirect("ten_url_dang_ky")
    else:
        form = TenFormTheoDe()

    return render(request, "ten_app/enroll.html", {"form": form})

def them_hoac_sua_view(request, id=None):
    # Nếu trên URL có truyền id -> Lấy bản ghi cũ ra để sửa; nếu không có -> None (Thêm mới)
    if id is not None:
        instance = get_object_or_404(Customer, id=id)
    else:
        instance = None

    if request.method == "POST":
        form = CustomerForm(request.POST, instance=instance)
        if form.is_valid():
            da_luu = form.save()
            messages.success(request, "Đã lưu thông tin thành công!")
            return redirect("ten_url_danh_sach")
    else:
        form = CustomerForm(instance=instance)

    return render(request, "ten_app/enroll.html", {
        "form": form,
        "instance": instance,
    })


# ------------------------------------------------------------------------------
# MẪU VIEW 3 (Dùng cho Câu 4 Đề mới): Trang Báo cáo Lọc tùy biến + Tính tổng cuối bảng
# ------------------------------------------------------------------------------
def bao_cao_view(request):
    # 1. Lấy tất cả bản ghi bảng chính, sắp xếp theo ngày tăng dần ("start_date")
    danh_sach = BangChinh.objects.all().order_by("start_date")

    # 2. Lấy dữ liệu lọc từ các ô input trên giao diện (method="get")
    tu_ngay = request.GET.get("tu_ngay", "").strip()
    den_ngay = request.GET.get("den_ngay", "").strip()
    chuyen_mon = request.GET.get("chuyen_mon", "").strip()

    # 3. Lọc theo Từ ngày (__gte là lớn hơn hoặc bằng >=)
    if tu_ngay:
        danh_sach = danh_sach.filter(start_date__gte=tu_ngay)

    # 4. Lọc theo Đến ngày (__lte là nhỏ hơn hoặc bằng <=)
    if den_ngay:
        danh_sach = danh_sach.filter(start_date__lte=den_ngay)

    # 5. Lọc theo chữ / chuyên môn:
    # - Nếu lọc trực tiếp trường của BangChinh: danh_sach.filter(name__icontains=chuyen_mon)
    # - Nếu lọc xuyên qua bảng trung gian (BangChinh -> lessons -> instructors -> expertise):
    if chuyen_mon:
        danh_sach = danh_sach.filter(
            lessons__instructors__expertise__icontains=chuyen_mon
        ).distinct()

    # 6. Duyệt từng dòng để đếm số lượng đăng ký & cộng dồn tổng cuối bảng
    danh_sach_ket_qua = []
    tong_luot_dang_ky = 0

    for item in danh_sach:
        # Lấy danh sách giảng viên/người phụ trách liên kết với mục này:
        ds_nguoi_phu_trach = BangPhu.objects.filter(lessons__course=item).distinct()

        # Đếm số lượt đăng ký của mục này:
        so_luong_dang_ky = item.enrollments.count()

        # Cộng vào tổng số lượt đăng ký toàn bảng:
        tong_luot_dang_ky = tong_luot_dang_ky + so_luong_dang_ky

        danh_sach_ket_qua.append({
            "main_item": item,
            "sub_items": ds_nguoi_phu_trach,
            "count": so_luong_dang_ky,
        })

    context = {
        "danh_sach_ket_qua": danh_sach_ket_qua,
        "tong_so_muc": len(danh_sach_ket_qua),
        "tong_luot_dang_ky": tong_luot_dang_ky,
        "tu_ngay": tu_ngay,
        "den_ngay": den_ngay,
        "chuyen_mon": chuyen_mon,
    }
    return render(request, "ten_app/report.html", context)
