3. MODEL, KIỂU DỮ LIỆU VÀ QUAN HỆ
======================================================================

3.1. Model là gì?

Model là lớp Python mô tả cấu trúc một bảng dữ liệu.
- Một class Model thường tương ứng một bảng.
- Một thuộc tính của Model tương ứng một cột.
- Một đối tượng Model tương ứng một dòng dữ liệu.

Ví dụ: class Customer là bảng khách hàng; thuộc tính Name là cột tên khách hàng.

3.2. Các kiểu Field thường dùng

- AutoField: số nguyên tự tăng, thường dùng làm khóa chính.
- CharField: văn bản ngắn, bắt buộc có max_length.
- TextField: văn bản dài.
- EmailField: văn bản có kiểm tra định dạng email.
- URLField: địa chỉ URL.
- IntegerField: số nguyên.
- FloatField: số thực dấu chấm động.
- DecimalField: số thập phân chính xác hơn cho tiền.
- DateField: ngày tháng.
- DateTimeField: ngày và giờ.
- BooleanField: đúng/sai.
- ForeignKey: khóa ngoại, quan hệ Một – Nhiều.
- ManyToManyField: quan hệ Nhiều – Nhiều.
- OneToOneField: quan hệ Một – Một.

Ví dụ:
    Ten = models.CharField(max_length=100)
    MoTa = models.TextField(blank=True)
    SoLuong = models.IntegerField()
    Gia = models.DecimalField(max_digits=10, decimal_places=2)
    NgayTao = models.DateField()

Giải thích:
- max_length: giới hạn độ dài CharField.
- blank=True: cho phép để trống ở Form/validation.
- null=True: cho phép lưu NULL trong CSDL. Không đồng nghĩa hoàn toàn với blank=True.
- max_digits: tổng số chữ số của DecimalField.
- decimal_places: số chữ số sau dấu thập phân.

3.3. Khóa chính id

Nếu không khai báo khóa chính, Django tự tạo khóa chính id dạng số tự tăng.

Nếu đề yêu cầu khai báo tường minh:

    id = models.AutoField(primary_key=True)

Không tạo thêm một trường id khác nếu Django đã tự tạo id. Chọn một cách phù hợp, không khai báo trùng.

3.4. Quan hệ Một – Nhiều (1-N)

Ví dụ:
- Một khách hàng có nhiều đơn hàng.
- Mỗi đơn hàng thuộc về một khách hàng.

Khóa ngoại phải đặt ở bảng NHIỀU, tức bảng Order:

    class Order(models.Model):
        Customer = models.ForeignKey(
            Customer,
            on_delete=models.CASCADE
        )

Cách nhớ:
Một Customer -> nhiều Order.
Do đó Order chứa ForeignKey trỏ Customer.

3.5. Quan hệ Nhiều – Nhiều (N-N)

Ví dụ:
- Một bài viết thuộc nhiều chuyên mục.
- Một chuyên mục chứa nhiều bài viết.

Dùng ManyToManyField:

    ChuyenMuc = models.ManyToManyField(ChuyenMuc)

Nếu bảng trung gian chỉ cần hai khóa ngoại, Django có thể tự tạo bảng trung gian.
Nếu đề yêu cầu bảng trung gian có thêm trường như ThuTu, phải tự tạo Model trung gian và dùng through:

    ChuyenMuc = models.ManyToManyField(
        ChuyenMuc,
        through='BaiVietChuyenMuc'
    )

3.6. on_delete – xử lý khi xóa bản ghi được tham chiếu

- models.CASCADE: xóa bản ghi liên quan theo.
- models.PROTECT: chặn xóa bản ghi đang được tham chiếu.
- models.SET_NULL: đặt khóa ngoại về NULL; trường FK phải có null=True.
- models.SET_DEFAULT: đặt về giá trị mặc định; phải khai báo default phù hợp.

Cách đọc đề:
- “Xóa khách hàng thì xóa đơn hàng liên quan” -> Order.Customer dùng CASCADE.
- “Chỉ xóa sách nếu không có đơn hàng liên quan” -> Order.Book dùng PROTECT.
- “Xóa kho thì xóa liên kết hàng hóa – kho” -> FK Kho trong bảng trung gian dùng CASCADE.
- “Xóa bài viết/chuyên mục thì xóa các dòng liên kết” -> hai FK trong bảng trung gian dùng CASCADE.

Không tự chọn CASCADE cho mọi trường. Đọc câu chữ về xóa trong đề.

3.7. __str__()

Dùng để biểu diễn đối tượng Model thành chuỗi dễ đọc, thường thấy trong Admin và dropdown ForeignKey.

Ví dụ:

    def __str__(self):
        return self.Ten

Hoặc:

    def __str__(self):
        return f'{self.id} - {self.Ten}'

Đề bài không quy định chi tiết các thuộc tính của Project và Task trong phần mô tả được cung cấp. Vì vậy, các thuộc tính dưới đây chỉ là ví dụ tối thiểu để minh họa quan hệ, không phải thuộc tính bắt buộc do đề quy định.

4.2. Phân tích quan hệ trước khi code

Một Project có nhiều Task.
Một Task chỉ thuộc một Project.

Do đó:
- Project là phía MỘT.
- Task là phía NHIỀU.
- ForeignKey đặt trong Task.

4.3. Code models.py mẫu

Mở projectp/models.py:

    from django.db import models

    class Project(models.Model):
        Name = models.CharField(max_length=100)
        Description = models.TextField(blank=True)

        def __str__(self):
            return self.Name

    class Task(models.Model):
        Title = models.CharField(max_length=200)
        Description = models.TextField(blank=True)
        Project = models.ForeignKey(
            Project,
            on_delete=models.CASCADE
        )

        def __str__(self):
            return self.Title

Giải thích từng phần:
- import models: lấy thư viện Model của Django.
- class Project(models.Model): khai báo bảng Project.
- Name: tên dự án, văn bản tối đa 100 ký tự.
- Description: mô tả dài, có thể bỏ trống trong ví dụ này.
- class Task(models.Model): khai báo bảng Task.
- Project = ForeignKey(...): mỗi Task liên kết một Project.
- on_delete=CASCADE: nếu xóa Project thì các Task tham chiếu Project đó cũng bị xóa.
- __str__: giúp nhìn thấy tên dễ đọc.

Nếu đề yêu cầu Task có thêm trạng thái, ngày bắt đầu, ngày kết thúc thì bổ sung đúng trường theo đề; không tự thêm khi đề không yêu cầu.

4.4. Tạo bảng trong SQLite

Sau khi lưu models.py, chạy:

    python manage.py makemigrations projectp

Lệnh này tạo file migration mô tả thay đổi Model.

Tiếp theo:

    python manage.py migrate

Lệnh này thực thi migration để tạo bảng thật trong SQLite.

Cách nhớ:
- makemigrations = tạo bản hướng dẫn thay đổi CSDL.

5.4. View chi tiết sách – mẫu

reviews/views.py:

    from django.shortcuts import render, get_object_or_404
    from .models import Book

    def book_details(request, pk):
        book = get_object_or_404(Book, pk=pk)
        reviews = book.review_set.all()

        ratings = [review.rating for review in reviews]

        if ratings:
            overall_rating = round(sum(ratings) / len(ratings))
        else:
            overall_rating = None

        context = {
            'book': book,
            'reviews': reviews,
            'overall_rating': overall_rating,
        }

        return render(
            request,
            'reviews/book_details.html',
            context
        )

Giải thích:
- request: thông tin yêu cầu từ trình duyệt.
- pk: ID của sách được truyền từ URL.
- get_object_or_404: tìm sách; không có thì trả trang 404 thay vì lỗi server.
- book.review_set.all(): lấy các Review liên quan đến Book theo quan hệ ForeignKey mặc định.
- ratings: danh sách điểm Review.
- if ratings: tránh chia cho 0 khi sách chưa có Review.
- context: dữ liệu chuyển sang Template.
- render(): ghép Template với dữ liệu và trả HTML.

Ghi chú:
- Phần bài tập yêu cầu hiển thị overall rating nhưng không nêu chính xác công thức tính ở phần đề. Cách tính trung bình ở trên là ví dụ hợp lý, đồng thời bài thực hành Chương 2 có hàm average_rating() để tính điểm trung bình.
- Nếu project đã có hàm average_rating() trong utils.py thì có thể import và sử dụng hàm đó thay cho đoạn tính trực tiếp.

6.3. Tạo SearchForm

reviews/forms.py:

    from django import forms

    class SearchForm(forms.Form):
        search = forms.CharField(
            required=False,
            min_length=3
        )

        search_in = forms.ChoiceField(
            choices=[
                ('title', 'Title'),
                ('contributor', 'Contributor'),
            ],
            required=True
        )

Giải thích:
- forms.Form: Form thường, không tự gắn vào một Model.
- search: hộp nhập văn bản.
- required=False: cho phép không nhập chuỗi.
- min_length=3: nếu nhập thì phải đủ ít nhất 3 ký tự.
- search_in: hộp chọn phạm vi.
- choices: các lựa chọn được phép.
- required=True: bắt buộc có lựa chọn Title hoặc Contributor.

LƯU Ý QUAN TRỌNG VỀ ĐỀ:
Đề vừa nói search_in là required, vừa nói form tìm kiếm nhanh ở base.html có thể không gửi search_in và cần mặc định là title. Hai điều này dễ gây xung đột: nếu ChoiceField bắt buộc mà request không gửi search_in thì Form có thể không hợp lệ.
Cách xử lý an toàn khi giữ required=True:
- Thêm hidden input search_in=title trong form tìm kiếm nhanh ở base.html.
- Form trên trang Search Results vẫn dùng dropdown để người dùng chọn.
Nếu giảng viên yêu cầu chính xác cách khác, ưu tiên cách được giảng viên hướng dẫn.

6.4. View book_search

Ví dụ dùng Model Book và Contributor của bài thực hành Bookr:

    from django.shortcuts import render
    from django.db.models import Q
    from .models import Book, Contributor
    from .forms import SearchForm

    def book_search(request):
        form = SearchForm(request.GET)
        books = Book.objects.none()
        search_text = ''

        if form.is_valid():
            search_text = form.cleaned_data.get('search', '').strip()
            search_in = form.cleaned_data.get('search_in', 'title')

            if search_text:
                if search_in == 'title':
                    books = Book.objects.filter(
                        title__icontains=search_text
                    )
                else:
                    contributors = Contributor.objects.filter(
                        Q(first_names__icontains=search_text) |
                        Q(last_names__icontains=search_text)
                    )

                    books = Book.objects.filter(
                        contributors__in=contributors
                    ).distinct()

        context = {
            'form': form,
            'books': books,
            'search_text': search_text,
        }

        return render(
            request,
            'reviews/search-results.html',
            context
        )

Giải thích từng phần:
- SearchForm(request.GET): nhận dữ liệu người dùng gửi bằng GET.
- Book.objects.none(): tạo QuerySet rỗng ban đầu.
- form.is_valid(): kiểm tra dữ liệu.
- cleaned_data: chỉ đọc sau khi gọi is_valid() và Form hợp lệ.
- strip(): bỏ khoảng trắng đầu/cuối.
- search_in: phạm vi tìm kiếm.
- title__icontains: tìm chuỗi con trong title, không phân biệt chữ hoa/thường.
- Q(... ) | Q(...): điều kiện OR.
- contributors__in: tìm Book có Contributor thuộc tập kết quả.
- distinct(): loại trùng Book do có thể khớp nhiều Contributor.
- render(): trả Template và dữ liệu.

Nếu đề yêu cầu đúng cách làm trong tài liệu là duyệt từng Contributor và kết hợp kết quả, có thể viết dạng:

    contributors = Contributor.objects.filter(
        first_names__icontains=search_text
    )

    contributors_last = Contributor.objects.filter(
        last_names__icontains=search_text
    )

    contributors = list(contributors) + list(contributors_last)

    books = []
    for contributor in contributors:
        for book in contributor.book_set.all():
            if book not in books:
                books.append(book)

Cách Q ở trên ngắn hơn; cách vòng lặp thể hiện đúng ý tưởng tách hai truy vấn và loại trùng như tài liệu bài tập.

7.3. View thêm/sửa Publisher

reviews/views.py:

    from django.shortcuts import render, get_object_or_404, redirect
    from django.contrib import messages
    from .models import Publisher
    from .forms import PublisherForm

    def publisher_edit(request, pk=None):
        if pk is not None:
            publisher = get_object_or_404(Publisher, pk=pk)
        else:
            publisher = None

        if request.method == 'POST':
            form = PublisherForm(
                request.POST,
                instance=publisher
            )

            if form.is_valid():
                saved_publisher = form.save()

                messages.success(
                    request,
                    'Publisher ' + str(saved_publisher) + ' saved successfully.'
                )

                return redirect('publisher_list')

        else:
            form = PublisherForm(instance=publisher)

        context = {
            'form': form,
            'instance': publisher,
            'model_type': 'Publisher',
        }

        return render(
            request,
            'reviews/instance-form.html',
            context
        )

Giải thích:
- pk=None: nếu không có ID thì thêm mới.
- Nếu có pk: lấy Publisher cũ.
- GET: tạo Form trống hoặc điền dữ liệu cũ.
- POST: nhận dữ liệu người dùng gửi.

    class ReviewForm(forms.ModelForm):

8.3. View review_edit

reviews/views.py:

    from django.shortcuts import (
        render,
        get_object_or_404,
        redirect
    )
    from django.contrib import messages
    from django.utils import timezone

    from .models import Book, Review
    from .forms import ReviewForm

    def review_edit(request, book_pk, review_pk=None):
        book = get_object_or_404(Book, pk=book_pk)

        if review_pk is not None:
            review = get_object_or_404(
                Review,
                pk=review_pk,
                book=book
            )
        else:
            review = None

        if request.method == 'POST':
            form = ReviewForm(
                request.POST,
                instance=review
            )

            if form.is_valid():
                saved_review = form.save(commit=False)
                saved_review.book = book

                if review is not None:
                    saved_review.date_edited = timezone.now()

                saved_review.save()

                messages.success(
                    request,
                    'Review for ' + book.title + ' created'
                )

                return redirect(
                    'book_details',
                    pk=book.pk
                )

        else:
            form = ReviewForm(instance=review)

        context = {
            'form': form,
            'instance': review,
            'model_type': 'Review',
            'related_model_type': 'Book',
            'related_instance': book,
        }

        return render(
            request,
            'reviews/instance-form.html',
            context
        )

Giải thích:
- book_pk: ID của Book, bắt buộc.
- review_pk=None: nếu không có ID Review thì thêm mới.
- get_object_or_404(Review, pk=review_pk, book=book): bảo đảm Review thuộc đúng Book đang mở.
- form.save(commit=False): tạo/cập nhật đối tượng Python nhưng chưa ghi xuống DB.
- saved_review.book=book: gán quan hệ Book.
- review is not None: đang sửa Review cũ.
- timezone.now(): lấy thời điểm hiện tại theo Django.
- saved_review.save(): ghi vào DB.
- redirect('book_details', pk=book.pk): trở về chi tiết Book.
- related_model_type và related_instance: hiển thị thông tin Book liên quan trên Form.

GHI CHÚ:

9A.2. Model code

qlbaiviet/models.py:

    from django.db import models
    from django.conf import settings

    class ChuyenMuc(models.Model):
        id = models.AutoField(primary_key=True)
        Ten = models.CharField(max_length=200)

        def __str__(self):
            return self.Ten

    class BaiViet(models.Model):
        id = models.AutoField(primary_key=True)
        TieuDe = models.CharField(max_length=250)
        NoiDung = models.TextField(blank=True)
        NgayTao = models.DateField()

        # Đề yêu cầu liên kết auth_user nhưng ảnh không nêu on_delete.
        # CASCADE dưới đây là lựa chọn để Model hoạt động; kiểm tra hướng dẫn của giảng viên.
        NguoiTao = models.ForeignKey(
            settings.AUTH_USER_MODEL,
            on_delete=models.CASCADE
        )

        ChuyenMuc = models.ManyToManyField(
            ChuyenMuc,
            through='BaiVietChuyenMuc'
        )

        def __str__(self):
            return self.TieuDe

    class BaiVietChuyenMuc(models.Model):
        id = models.AutoField(primary_key=True)

        BaiViet = models.ForeignKey(
            BaiViet,
            on_delete=models.CASCADE
        )

        ChuyenMuc = models.ForeignKey(
            ChuyenMuc,
            on_delete=models.CASCADE
        )

        ThuTu = models.IntegerField()

Giải thích:
- NguoiTao liên kết bảng người dùng mặc định của Django.
- BaiViet.ChuyenMuc là N-N.
- through='BaiVietChuyenMuc' chỉ rõ bảng trung gian.
- Hai ForeignKey trong bảng trung gian dùng CASCADE để xóa liên kết khi bài viết hoặc chuyên mục bị xóa.
- ThuTu là trường bổ sung của bảng trung gian.

LƯU Ý QUAN TRỌNG:
ModelForm không tự giải quyết mọi trường hợp bảng ManyToMany có through Model tùy chỉnh với trường bổ sung bắt buộc như ThuTu. Nếu đề yêu cầu gán chuyên mục và thứ tự, phải tạo bản ghi BaiVietChuyenMuc riêng. Đừng nghĩ form.save() tự tạo đủ ThuTu.

9A.9. View thêm/sửa bài viết

    from django.shortcuts import render, get_object_or_404, redirect
    from django.contrib import messages
    from .models import BaiViet
    from .forms import BaiVietForm

    def baiviet(request, idbaiviet=None):
        if idbaiviet is not None:
            instance = get_object_or_404(
                BaiViet,
                id=idbaiviet
            )
        else:
            instance = None

        is_new = instance is None

        if request.method == 'POST':
            form = BaiVietForm(
                request.POST,
                instance=instance
            )

            if form.is_valid():
                saved_baiviet = form.save()

                if is_new:
                    messages.success(
                        request,
                        'Bài viết ' + saved_baiviet.TieuDe + ' đã được thêm thành công'
                    )
                else:
                    messages.success(
                        request,
                        'Thông tin chỉnh sửa bài viết ' + saved_baiviet.TieuDe + ' đã được lưu lại'
                    )

                return redirect('dsbaiviet')

        else:
            form = BaiVietForm(instance=instance)

        return render(
            request,
            'qlbaiviet/baiviet.html',
            {
                'form': form,
                'instance': instance
            }
        )

9B.2. Model code

    from django.db import models

    class Kho(models.Model):
        id = models.AutoField(primary_key=True)

        Ten = models.CharField(max_length=100)

        DiaChi = models.CharField(
            max_length=255,
            blank=True
        )

        def __str__(self):
            return f'{self.id} - {self.Ten}'

    class HangHoa(models.Model):
        id = models.AutoField(primary_key=True)

        Ten = models.CharField(max_length=255)

        MoTa = models.TextField(blank=True)

        Kho = models.ManyToManyField(
            Kho,
            through='KhoHangHoa'
        )

        def __str__(self):
            return self.Ten

    class KhoHangHoa(models.Model):
        id = models.AutoField(primary_key=True)

        HangHoa = models.ForeignKey(
            HangHoa,
            on_delete=models.CASCADE
        )

        Kho = models.ForeignKey(
            Kho,
            on_delete=models.CASCADE
        )

Giải thích:
- Kho có thể chứa nhiều HangHoa.
- HangHoa có thể nằm ở nhiều Kho.
- Đây là N-N nên dùng ManyToManyField.
- through chỉ bảng trung gian KhoHangHoa.
- Hai FK trong KhoHangHoa dùng CASCADE theo yêu cầu xóa liên kết.
- DiaChi và MoTa có blank=True vì đề ghi không bắt buộc.

9C.2. Model code

store/models.py:

    from django.db import models

    class Book(models.Model):
        Title = models.CharField(max_length=200)
        Author = models.CharField(max_length=255)

        Price = models.DecimalField(
            max_digits=10,
            decimal_places=2
        )

        Stock = models.IntegerField()
        Published_date = models.DateField()

        def __str__(self):
            return self.Title

    class Customer(models.Model):
        Name = models.CharField(max_length=100)
        Email = models.EmailField()
        Phone = models.CharField(max_length=15)
        Address = models.CharField(max_length=255)

        def __str__(self):
            return self.Name

    class Order(models.Model):
        Customer = models.ForeignKey(
            Customer,
            on_delete=models.CASCADE
        )

        Book = models.ForeignKey(
            Book,
            on_delete=models.PROTECT
        )

        Quantity = models.IntegerField()
        Order_date = models.DateField()

        Total_price = models.DecimalField(
            max_digits=12,
            decimal_places=2
        )

        def __str__(self):
            return f'Order {self.id}'

Giải thích:
- Customer FK CASCADE: xóa khách hàng thì đơn hàng của khách hàng bị xóa.
- Book FK PROTECT: không cho xóa sách nếu còn đơn hàng tham chiếu.
- Price và Total_price dùng DecimalField cho dữ liệu tiền.
- max_digits và decimal_places là tham số cần chọn vì đề chỉ nói kiểu số thập phân mà không chỉ rõ độ chính xác. Ví dụ 10,2 và 12,2 ở trên là lựa chọn minh họa; nếu giảng viên có quy định khác thì dùng theo giảng viên.

9C.9. View edit_customer

    from django.shortcuts import render, get_object_or_404, redirect
    from django.contrib import messages
    from .models import Customer
    from .forms import CustomerForm

    def edit_customer(request, id=None):
        if id is not None:
            customer = get_object_or_404(
                Customer,
                id=id
            )
        else:
            customer = None

        is_new = customer is None

        if request.method == 'POST':
            form = CustomerForm(
                request.POST,
                instance=customer
            )

            if form.is_valid():
                saved_customer = form.save()

                if is_new:
                    messages.success(
                        request,
                        'Đã thêm khách hàng ' + saved_customer.Name + ' thành công'
                    )
                else:
                    messages.success(
                        request,
                        'Đã cập nhật khách hàng ' + saved_customer.Name + ' thành công'
                    )

                return redirect('order_list')

        else:
            form = CustomerForm(instance=customer)

        return render(
            request,
            'store/edit_customer.html',
            {
                'form': form,
                'customer': customer
            }
        )

11. KIỂM TRA LỖI – ĐỌC TRACEBACK VÀ SỬA ĐÚNG FILE
======================================================================

11.1. TemplateDoesNotExist

Nguyên nhân:
- Sai tên Template trong render().
- Sai vị trí thư mục.
- Sai tên App.

Nếu View gọi:

    render(request, 'store/order_list.html', context)

Thì cấu trúc nên là:

    store/templates/store/order_list.html

11.2. NoReverseMatch

Nguyên nhân:
- Template gọi URL name không tồn tại.
- URL cần tham số nhưng quên truyền.
- Số tham số không khớp.

Ví dụ:
    path('books/<int:id>/', views.book_detail, name='book_detail')

Thì Template phải truyền ID:

    {% url 'book_detail' book.id %}

11.3. no such table

Nguyên nhân:
- Chưa chạy makemigrations.
- Chưa chạy migrate.
- Model chưa nằm trong App được đăng ký.

Cách xử lý:
    python manage.py makemigrations
    python manage.py migrate

11.4. No module named ...

Nguyên nhân:
- Sai tên App hoặc package.
- Chạy lệnh ở sai môi trường Python.
- App chưa được tạo.
- Import sai đường dẫn.

11.5. FieldError

Nguyên nhân:
- Tên trường trong filter(), list_display, search_fields không tồn tại.
- Viết sai chữ hoa/thường.
- Dùng tên thuộc tính khác tên trong models.py.

Cách sửa:
Mở models.py, đối chiếu đúng tên thuộc tính.

11.6. IntegrityError

Nguyên nhân có thể:
- Bỏ trống trường bắt buộc.
- Gán khóa ngoại không tồn tại.
- Vi phạm ràng buộc duy nhất.
- Xóa bản ghi đang được bảo vệ.

Cách sửa:
Đọc dòng cuối traceback và kiểm tra dữ liệu gửi vào.

11.7. CSRF verification failed

Kiểm tra Template có:

    {% csrf_token %}

Kiểm tra Form có method="post".
Không xóa CSRF chỉ để tránh lỗi.

11.8. Form không lưu

Kiểm tra đúng thứ tự:
1. HTML Form có method="post".
2. Có csrf_token.
3. View có if request.method == 'POST'.
4. Form nhận request.POST.
5. Có form.is_valid().
6. Có form.save().
7. Nếu dùng commit=False thì cuối cùng phải gọi obj.save().
8. Sau khi lưu mới redirect.

11.9. View lỗi do thiếu tham số

Nếu URL:

    path('books/<int:pk>/', views.book_detail)

Thì View phải nhận:

    def book_detail(request, pk):

Không đặt tên pk ở URL nhưng lại nhận id trong View, trừ khi URL truyền đúng keyword id.

11.10. Cách debug có thứ tự

1. Đọc dòng cuối traceback.
2. Xác định file và số dòng.
3. Xác định lỗi thuộc URL, View, Model, Template, Form, Database hay Settings.
4. Đối chiếu tên biến và tên trường.
5. Sửa ít nhất có thể.
6. Chạy lại.
7. Nếu còn lỗi, đọc traceback mới; không đoán.
