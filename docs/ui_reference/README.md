# Ảnh tham khảo UI (do người dùng cung cấp)

Các file này dùng để **xác định lỗi hiện tại** và thống nhất yêu cầu UI, không phải giao diện mẫu để sao chép từng pixel.

01 Listening list — bộ lọc thiếu chọn chủ đề.
02 Reading list — bộ lọc cần chuẩn hóa với các module khác.
03 Reading test header — passage và palette, trạng thái đầu bài.
04 Reading test scroll — xuống câu hỏi thì passage biến mất; nhãn TFNG lặp.
05 Writing filter — nhiều hàng quá dài, không cùng kiểu Speaking.
06 Vocabulary footer — footer nằm giữa nội dung.
07 Management footer — footer che bảng dữ liệu/sidebar.
08 Register footer — footer che form, thông tin tài khoản đã làm mờ để bảo vệ riêng tư.
09 Speaking management — danh sách trống (database ZIP có 0 đề Speaking).
10 Writing result overview — tham khảo bố cục điểm/radar/4 tiêu chí.
11 Writing result evidence — tham khảo cách trình bày dẫn chứng, lỗi và hướng sửa.

**Quy tắc:** Sửa root cause, kiểm tra bằng trang thật, không dùng ảnh này làm bằng chứng rằng code mới đã được test.
